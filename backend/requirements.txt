# Runtime dependencies, pinned exactly.
#
# Exact pins rather than ranges: this application's correctness claims are about
# numerical behaviour — a scaler's centre, an encoder's cross-fitting, a quantile — and
# a minor release of pandas or scikit-learn can move those without any code changing.
# A pipeline that produced one dataset yesterday and a different one today, with the
# same input and the same seed, would falsify the determinism guarantee in §6.
#
# Install:  pip install -r requirements.txt

# falls back to permutation importance — clearly labelled — when neither can read a
# fitted model.

# requirements are open-ended and would otherwise be free to move numpy. Verified on

# chain, so nothing here is built from source.
